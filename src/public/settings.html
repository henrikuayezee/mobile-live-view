    Connect over USB

    The most reliable option, and immune to the Wi-Fi drop-outs that end a wireless session. Plug the phone in, enable Developer options → USB debugging, then accept the "Allow USB debugging?" prompt on the phone. It appears in the list above as a USB device; press Refresh if it does not show up straight away.

    Pair with a QR code

    Easiest option, nothing to type. On the phone: Settings → Developer options → Wireless debugging → "Pair device with QR code", then point it at the code below.

    Or pair with a code

    On the phone: Settings → Developer options → Wireless debugging → "Pair device with pairing code". Enter the address and code shown there.
